# Nutriendo Hábitos

Web de Andrea Argüello Arbe, dietista-nutricionista en Valladolid.

- Página estática: `index.html` + imágenes en `img/`.
- Sin claves, sin base de datos, sin servicios de pago.
- `enviar.php` envía el formulario a nutricion.arguello@gmail.com con el asunto «RESERVA WEB» usando el correo del hosting (necesita PHP; GitHub Pages no lo ejecuta).
- El formulario también puede enviarse por WhatsApp, y hay botón para llamar.
